# VK Playground — 郭慶禮 Vincent Kuo 的遊戲化履歷

一份可以「玩」的視覺設計師履歷：用鍵盤、滑鼠或手機上的虛擬手把操作主角「小禮」，走過六個章節認識我。

| 章節 | 內容 |
|---|---|
| 0 起始村莊 | 關於我 |
| 1 冒險時光驛站 | 經歷 |
| 2 道具庫 | 技能與工具 |
| 3 委託公會 | 服務與合作流程 |
| 4 作品展覽館 | 作品集 |
| 5 傳送門 | 聯絡我 |

## 操作
- ← → 走路、Shift 奔跑、Space / ↑ 跳躍、↓ 蹲下、E 互動、Esc 章節選單
- 手機：十字鍵、A 奔跑、B 跳躍

## 技術
單一 `index.html`（React 18 UMD、SVG、CSS 動畫；圖片已壓縮內嵌），可直接用 GitHub Pages 發佈。
